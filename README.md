# 智能物流搬运小车（2024 年工程训练大赛）

2024 年全国大学生工程训练大赛智能物流搬运小车，多板协同架构。

## 目录结构

```
├── 比赛最终代码/           # 决赛代码
├── 初赛/                   # 初赛版本（Keil 工程）
├── 工训/
│   ├── gong_xun_stm32-main/           # STM32CubeMX + MDK 工程 (project03)
│   └── 三板通信西门子最终代码/
│       ├── rct6 openmv cv 语音/       # OpenMV 视觉 + 语音交互板
│       └── rct6 蓝牙避障/             # 蓝牙遥控 + 避障板
├── 佟学长工训/             # 历史参考版本
├── 工训.HMI                # 西门子 HMI 组态
└── max.py                  # 辅助脚本
```

## 技术栈

- **三块 STM32 板卡协同**（主控 / 视觉语音 / 蓝牙避障）
- OpenMV 机器视觉（物料识别与定位）
- 蓝牙通信、超声波避障
- 西门子 HMI 上位机监控
- STM32CubeMX + Keil MDK
